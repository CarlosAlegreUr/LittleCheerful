# Little Cheerful

**Navigation-Based Continuous Learning System**

Little Cheerful is an AI learning assistant that helps users build deep understanding through:
- Adaptive concept trees
- Socratic questioning (not testing)
- Verified source citations
- Multi-language support
- User-controlled learning paths

## Usage

Copy the `littleCheerful/` directory to your `.claude/` folder and run `/start-learning` to begin.

## What's Inside

- **`littleCheerful/`** - Main product (copy-paste ready)
- **`littleCheerful(prev)/`** - Previous version backup
- **`.claude/`** - Development/testing version

## Core Philosophy

**You learn. The AI guides, questions, and verifies.**

Learning happens through progressive concept navigation, evidence-based explanations, and active thinking - not passive consumption.
